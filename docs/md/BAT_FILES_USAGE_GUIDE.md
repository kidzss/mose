# 📋 BAT文件使用说明指南

## 📖 概述

本项目包含多个BAT批处理文件，用于不同的股票分析和投资自动化任务。每个BAT文件都有其特定的用途和使用场景。

---

## 🎯 持仓分析相关

### 1. `run_portfolio_analysis.bat` - 一次性手动执行

**📊 功能描述**
- 立即分析当前持仓股票表现
- 生成完整的盈亏统计报告
- 包含技术指标和市场情绪分析
- 自动发送邮件报告

**🎯 适用场景**
- 需要快速查看当前持仓状态
- 临时生成持仓分析报告
- 手动触发分析任务

**📈 分析股票**
- **持仓股票**: AMD, GOOGL, PFE, NVDA, TSLA, ADBE
- **观察股票**: MSFT, EOG, PHM, CF

**📧 邮件配置**
- 收件邮箱: kidzss@gmail.com
- 报告格式: HTML格式，包含图表和详细分析

**🚀 使用方法**
```bash
# 双击运行或命令行执行
run_portfolio_analysis.bat
```

**📊 报告内容**
- 持仓股票详细分析
- 盈亏情况统计
- 技术指标分析
- 市场环境评估
- 个性化投资建议

---

### 2. `start_monitor.bat` - 持续服务 ⭐ (推荐日常使用)

**📊 功能描述**
- 每个交易日美股收盘后自动发送报告
- 后台持续运行的监控服务
- 自动更新股票数据
- 生成专业持仓分析报告

**🎯 适用场景**
- 日常使用，自动化监控
- 无需手动干预的定期报告
- 长期持续的投资监控

**⏰ 定时发送时间**
- **夏令时** (3-10月): 北京时间 04:30
- **冬令时** (11-2月): 北京时间 05:30
- 即美股收盘后30分钟自动发送

**📧 邮件配置**
- 收件邮箱: kidzss@gmail.com
- 自动发送，无需手动触发

**🚀 使用方法**
```bash
# 双击运行，服务将持续运行
start_monitor.bat

# 停止服务：按 Ctrl+C
```

**💡 注意事项**
- 服务启动后会一直运行，直到手动停止
- 建议在电脑开机时自动启动
- 确保网络连接稳定

### 3. `start_portfolio_scheduler.bat` - 定时调度 (高级用户)

**📊 功能描述**
- 灵活的多层次分析调度
- 支持日报、周报、月报
- 可配置的调度策略
- 投资组合优化建议

**🎯 适用场景**
- 高级用户自定义调度需求
- 需要不同频率的分析报告
- 投资组合优化分析

**📅 调度计划**
- **每日简报**: 交易日 16:30
- **每周深度分析**: 每周日 20:00
- **每月组合优化**: 每月第一个周日 20:00

**📊 分析内容**
- 持仓股票实时表现分析
- 盈亏统计和风险评估
- 技术指标和市场情绪
- 个性化投资建议
- 投资组合优化建议

**🚀 使用方法**
```bash
# 双击运行，启动调度服务
start_portfolio_scheduler.bat

# 停止服务：按 Ctrl+C
```

**⚙️ 配置文件**
- 配置文件: `portfolio_scheduler_config.json`
- 可自定义调度时间和分析参数

## 🛠️ 使用建议

### 📋 日常使用推荐

1. **日常监控**: 使用 `start_monitor.bat` ⭐
   - 一次启动，持续监控
   - 每个交易日自动发送报告
   - 最适合日常使用

2. **临时查看**: 使用 `run_portfolio_analysis.bat`
   - 需要立即查看持仓状态时
   - 手动触发分析

3. **高级配置**: 使用 `start_portfolio_scheduler.bat`
   - 需要自定义调度策略
   - 多层次分析需求

### ⚠️ 注意事项

1. **网络要求**
   - 确保网络连接稳定
   - 需要访问股票数据源

2. **邮件配置**
   - 确认邮件配置正确
   - 检查垃圾邮件文件夹

3. **Python环境**
   - 确保Python环境配置正确
   - 安装所需依赖包

4. **系统资源**
   - 持续运行的服务会占用系统资源
   - 建议在性能较好的电脑上运行

### 🔧 故障排除

**常见问题及解决方案**

1. **邮件发送失败**
   - 检查网络连接
   - 验证邮件配置
   - 查看错误日志

2. **数据获取失败**
   - 检查数据源可用性
   - 验证网络连接
   - 重试运行

3. **Python错误**
   - 检查Python环境
   - 安装缺失的依赖包
   - 查看详细错误信息

### 📞 技术支持

如遇到问题，请：
1. 查看错误日志信息
2. 检查系统配置
3. 联系技术支持

## 🏗️ 策略架构体系

### 1. 核心策略层（3个主要策略）

#### 1.1 牛牛策略V3 (NiuniuStrategyV3) - 权重50%
**策略特点：**
- 基于趋势跟踪和动量突破的中长期策略
- 多周期趋势跟踪（快速均线10日，慢速均线30日）
- 动量突破确认（RSI 14日，超卖25，超买75）
- 波动率自适应（ADX 14日，阈值20）

**选股标准：**
```python
# 技术指标要求
- 快速均线 > 慢速均线（上升趋势）
- RSI在25-75之间（避免极端超买超卖）
- ADX > 20（趋势强度确认）
- 成交量比率 > 1.2（成交量放大）
- 波动率适中（ATR控制风险）

# 风险控制
- 止损：8%
- 止盈：25%
- 追踪止损：5%
- 最大仓位：80%
- 最小仓位：40%
```

**适用场景：**
- 中长期投资（持仓3天以上）
- 趋势明确的市场环境
- 大盘股和成长股

#### 1.2 TDI策略 (TDIStrategy) - 权重30%
**策略特点：**
- 短期技术分析策略
- 基于交易者动态指数（Trader's Dynamic Index）
- 结合RSI、移动平均和波动率带

**选股标准：**
```python
# TDI核心指标
- RSI基线突破
- 价格带突破确认
- 成交量配合验证
- 短期动量强劲

# 适用条件
- 短期交易机会（1-5天）
- 波动性较高的股票
- 技术面主导的市场
```

#### 1.3 CPGW策略 (CPGWStrategy) - 权重20%
**策略特点：**
- 补充策略，提供多样化信号
- 基于价格行为和成交量分析
- 关注支撑阻力位突破

**选股标准：**
```python
# CPGW关键要素
- 关键价位突破
- 成交量确认
- 价格形态识别
- 风险收益比评估
```

### 2. 组合策略层 (CombinedStrategy)

**权重分配：**
- 牛牛策略V3：50%（主导策略）
- TDI策略：30%（短期补充）
- CPGW策略：20%（形态确认）

**信号生成机制：**
```python
# 组合信号计算
combined_signal = (
    0.50 * niuniu_signal +
    0.30 * tdi_signal +
    0.20 * cpgw_signal
)

# 信号确认条件
- 信号强度 > 0.6
- 至少2个策略同向
- 市场环境适应性调整
```
